# Panther Watch  

**Panther Watch** is a Flutter app designed to enhance campus safety and engagement at Georgia State University (GSU).  

---

1. **Clone the repository**:  
   ```bash
   git clone https://github.com/your-repo/panther-watch.git
   cd panther-watch

2. **Install Flutter dependencies**:
Ensure Flutter is installed (setup guide). Then run:

    ```bash
    Copy code
    flutter pub get
    Run the app:

    ```bash
    Copy code
    flutter run

✨ **Key Features**
Message Boards: Chat with other users.
Location Sharing: Send real-time locations to GSU Police.
Upcoming Events: View and stay updated on campus events.
Activity Reporting: Report suspicious activities.
Campus Resources: Quick access to GSU resources.
Enjoy using Panther Watch to stay safe and connected! 🐾
